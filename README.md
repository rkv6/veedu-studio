# Veedu Studio (concept)

Concept site for a fictional interior design and real estate studio in Thiruvananthapuram. React, TypeScript, Vite.

Enquiries open WhatsApp through `api/enquiry.js`. Set the `WHATSAPP_NUMBER` environment variable in Vercel (digits with country code, for example `919876543210`) so the number never appears in the repo or the page source.
